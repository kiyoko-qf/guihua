# 桂花糕、旧车票和一只打翻的盘子

纯文字本格推理 · v0.1 · 约 15 分钟 · 无恐怖

一个中秋夜，外婆说「桂花糕不见了」。
桌上只剩一只空盘，盘边的标签写着「含桂花」；针线盒里那张旧火车票，也不见了。

**线上地址**：https://kiyoko-qf.github.io/guihua/
（手机扫码：`分享二维码.png`）

## 怎么玩

双击 `启动.bat`，或桌面上的同名快捷方式（用 Edge 打开）。

四章：

1. **现场** —— 点开 11 个地点，找齐 14 条线索。
2. **三种说法** —— 舅舅、林芳、小满各有一个解释；每个解释挑 2 条最能推翻它的物证。
3. **还原** —— 把那个下午的五件事按时间排好。
4. **那句话** —— 外婆为什么只说「不见了」。

通关后可以看「物证地图」：四条证据链各自指向哪一条真相。

## 怎么改

所有文字都在 `data.js`，不用碰代码：

- `locations` —— 地点与它给出的线索
- `evidence` —— 线索正文（E1–E14）
- `claims` —— 三种说法、正确反驳证据（`refute`）、作答提示
- `timeline` —— 五件事与正确顺序
- `motive` / `ending` / `review` —— 最后一问、结局、复盘

改完直接刷新页面即可。存档在浏览器 localStorage（键名 `guihua.case.v1`），
页面加 `?fresh=1` 可强制从头开始。
